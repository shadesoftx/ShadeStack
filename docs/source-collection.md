# Source Collection Tracker

This is the working tracker for gathering ShadeStack source links in a trustworthy, accurate way. Use it to collect the bulk of official product documentation before updating BookStack product pages.

Last updated: 2026-06-03

## Trust Rules

Use sources in this order:

1. Official vendor public website.
2. Official vendor support, document, warranty, or resource library.
3. Official vendor dealer/pro portal.
4. Dated file or link sent directly by the vendor rep.
5. Internal field note or employee-maintained reference.

Avoid reseller blogs, copied PDFs, SEO pages, unverified forum posts, and old distributor pages unless they are marked `Pending Review` and linked only as temporary evidence.

## Collection Statuses

| Status | Meaning |
|---|---|
| Complete | Current official source is captured and verified. |
| Partial | Some official source material is captured, but one or more outcome resources are missing. |
| Needed | Source has not been collected yet. |
| Pending Review | Source exists but needs human validation before use. |
| Login Required | Source is behind a dealer/pro portal. Store only the portal URL and 1Password item name. |
| Rep Needed | Vendor rep must confirm the current source or send a file/link. |
| Not Applicable | Resource does not apply to this vendor/product. |

## Collection Fields

Every collected source should capture:

| Field | Required content |
|---|---|
| Vendor | Vendor name from `docs/products.md`. |
| Product/category | Product family, category, or brand-wide source. |
| Outcome resource | Install Guides, Product Specs, Sales Collateral, Warranty, Portal, Rep Contact, or Other. |
| Source URL or location | Public URL, portal URL, or internal location. Do not store credentials. |
| Access level | Public, Login Required, Rep Provided, Internal, or Pending Review. |
| Date verified | Date the source was checked. |
| Verified by | Employee initials/name. |
| Status | Complete, Partial, Needed, Pending Review, Login Required, Rep Needed, or Not Applicable. |
| Next action | Specific action needed to close the row. |

```text
Hi [Rep Name],

We are updating our internal ShadeStack product documentation and want to make sure our team uses the current official sources.

Can you send or confirm the best current links/files for:

1. Install guides
2. Product specs / technical sheets
3. Sales collateral / brochures
4. Warranty terms and claim process
5. Dealer portal or resource library URL
6. Any discontinued/current-line notes we should know before quoting

Please include the date/version if the document is a PDF.
```

## Completion Rule

A vendor is ready for deeper BookStack page writing when each of the four outcome resources has one of these documented states:

- `Complete`: official source captured and verified.
- `Partial`: source exists but needs product-level mapping.
- `Login Required`: portal URL and 1Password item are recorded.
- `Rep Needed`: rep request is sent and tracked.
- `Not Applicable`: resource truly does not apply.
